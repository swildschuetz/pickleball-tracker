# 🏓 Pickleball-Tracker

Statische Web-App fürs Pickleball: Spieler anlegen, Paarungen vorschlagen, Ergebnisse eintragen und Tabelle, Profil sowie Verlauf ansehen.

Live: https://swildschuetz.github.io/pickleball-tracker/

Daten liegen lokal im Browser (localStorage) und lassen sich im Reiter „Spieler“ über Export/Import übertragen.
